# 02. データを登録する

AgentBlume でエージェントを作る最初の一歩は、ツールに読ませるデータを登録することだ。この章では、手元の CSV・JSON ファイルや社内のデータベースをどう登録するか、登録したデータの列をAgentBlumeがどう読み取って見せるかを説明する。

## この章でできるようになること

- CSV・JSON ファイルを「データソース」画面から登録する。
- サーバー側で構成済みの PostgreSQL 接続を、データソースとして登録する。
- 登録したデータの列（期間として読める列・値として使える数値の列・複数ソースをつなげる結合キー）を、AgentBlumeがどう自動で見つけているかを理解する。

## この章の内容

| ファイル | 内容 |
|---|---|
| [01 データの登録](./01-register-data.md) | 「データソース」画面での CSV・JSON のアップロード手順、文字コードと列の型の扱い、データベース接続の登録 |
| [02 データの下調べ（プロファイル）](./02-data-profile.md) | 期間の列・カテゴリの列・結合できる相手の組み合わせを、AgentBlumeがどう自動検出するか |

## 前提

- 左ナビの「**データソース**」画面を使う（画面へは「作る」グループから入る）。
- モデル（LM Studio・OpenAI など）の設定は不要。この章の操作はモデルを使わない。
- 登録したデータは次章「[03 ツールを作る](../03-tools/README.md)」でツールの入力として使う。
