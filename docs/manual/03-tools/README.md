# 03 ツールを作る

エージェントが呼び出す「ツール」を作る章。ツールは、登録したデータを決まった手順で読み・絞り・計算して返す部品で、エージェントはこれを呼んで確かな数字や一覧を手に入れる。ツールの作り方は 3 通りあり、どれで始めても同じキャンバスで確かめて保存する。

> **いちばん楽な作り方: 設計アシスタントと一緒に作る。**
> ツール画面の「設計アシスタント」を押し、「都道府県別の人口を年次に絞って多い順に10件返して」のように日本語で頼むと、キャンバスにノードが置かれていく。気に入らなければ 1 手で取り消せる。**はじめての人はまず [05 設計アシスタントと一緒に設計する](./05-design-assistant.md) を読む**とよい。

## 作り方の選び方

| こんなとき | 作り方 | 読む節 |
|---|---|---|
| やりたいことを言葉で説明できる。ノードの名前はまだ分からない | 設計アシスタントに頼む | [05](./05-design-assistant.md) |
| 時系列の取り出し・ランキング・前期比・2 つのデータの比など、よくある形 | テンプレートから作成 | [04](./04-from-templates.md) |
| 細かく自分で組みたい / 作ったツールを手直ししたい | キャンバスでノードを置く | [02](./02-build-on-canvas.md)・[03](./03-node-reference.md) |

3 つは混ぜて使える。テンプレートで骨組みを作り、設計アシスタントに「地域でも絞れるように」と頼み、最後に自分で設定を微調整する、という流れが一番早い。

## 始める前に

- ツールが読むデータを先に登録しておく（[02 データを登録する](../02-data/01-register-data.md)）。ツール一覧が空のときは「データソース画面を開く」リンクも出る。
- 設計アシスタント・関数電卓の「AIに式を書かせる」・AI判定ノードはモデルを使う。先に [モデルの設定](../01-getting-started/02-model-settings.md) を済ませておく。キャンバスで組む・テンプレートから作る・プレビューはモデルなしで動く。
