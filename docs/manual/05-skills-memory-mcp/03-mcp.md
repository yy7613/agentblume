# MCPサーバー

この節では、外部のMCPサーバーを登録し、接続を確かめる方法を説明する。登録したサーバーのツールは、エージェント編集画面の「MCPサーバー」で選ぶとエージェントへ注入できる（[ツール・スキル・Wikiなどを持たせる](../04-agents/03-attach-tools-and-more.md)）。

## 画面の場所

左ナビ「運用 → **MCP**」を開く。画面は上下2段で、上が「**MCPクライアント（外部サーバー接続）**」（この節の主題）、下が「**MCP公開**」（AgentBlume自身のツールをMCPサーバーとして外部へ公開する機能）である。

> **MCP公開は現時点では使えない**。認証・認可・監査・公開エンドポイントの実装が整うまで安全側に遮断されており、画面には「**外部公開は利用できません**」と表示され、「**MCPサーバーを公開**」ボタンは押せない。マニフェストのプレビューだけは確認できる。

## サーバーを登録する（フォーム）

「**フォーム**」タブで次を入力する。

1. 「**名前**」（保存後は変更できない。同じ名前で保存すると更新になる）。
2. 「**トランスポート**」で `stdio`（コマンドを起動して接続）か `http`（URLへ接続）を選ぶ。

**stdio** の場合:

| 項目 | 説明 |
|---|---|
| コマンド | 例 `npx` |
| 引数（1行1件） | 例 `-y` / `@modelcontextprotocol/server-filesystem` |
| 環境変数（1行1件 `KEY=VALUE`） | 例 `API_TOKEN=xxxx`。保存済みの値は暗号化され、表示は `***` になる。`***` のままなら値は変わらない |
| 作業ディレクトリ（任意） | 例 `C:\workspace` |

> Windowsでnpx系サーバーを使う場合、コマンドを `cmd`、引数を `/c`, `npx`, … とする必要がある場合がある。

**http** の場合:

| 項目 | 説明 |
|---|---|
| URL | 例 `https://example.com/mcp` |
| ヘッダー（1行1件 `Header: value`） | 例 `Authorization: Bearer xxxx`。値は暗号化され `***` 表示になる |

どちらの種類でも「**このサーバーを無効化（実行時はスキップ）**」を選べる。無効化したサーバーは、エージェントに割り当てられていても実行時にツールが注入されない。

3. 「**サーバーを保存**」を押す。

## 接続をテストする

登録済みサーバーの行にある「**テスト**」を押す。成功すると、そのサーバーが公開しているツールの一覧（ツール名と説明）が出る。ツールを1つも公開していない場合は「接続成功・公開ツールなし」、失敗した場合はエラー内容が出る。

行の「**編集**」で内容を直し、「**削除**」（確認ダイアログを経由。参照しているエージェントはそのツールを失う旨の注意が出る）で登録を外せる。

## JSONで一括編集する

「**JSON**」タブでは、登録済みサーバー全体を1つのJSONドキュメント（`mcpServers`オブジェクト）として編集できる。

- **「適用」は全置換**である。ドキュメントに記載の無いサーバーは削除される。
- 資格情報（env・headers）は `***` で伏せられる。**そのまま適用すれば保存済みの値が維持される**。変えたい値だけ実際の値に書き換える。このため、書き出したドキュメントをそのまま他のツールへ貼り付けることはできない。

## 権限について

MCPサーバーの設定変更と接続テストには `mcp-server:operate` 権限（operator または workspace-admin ロール）が必要である。権限が無いアカウントでは、該当ボタンが無効化され「**閲覧のみ**」という案内が出る（stdioの設定はサーバーホスト上でのコード実行に相当するため、権限で絞られている）。

## うまくいかないとき

| 症状 | 原因・直し方 |
|---|---|
| 保存ボタンが押せない | 「名前」が空、またはstdioでコマンド・httpでURLが空。埋めてから保存する |
| テストが失敗する | サーバー側の起動状況・URL・資格情報を確認する。stdioでは特にWindowsでの`cmd /c npx ...`形式を確認する |
| ボタンがすべて無効になっている | `mcp-server:operate` 権限が無いアカウントで開いている。権限を持つ利用者に依頼する |
| エージェントがMCPツールを呼ばない | エージェント側の「MCPサーバー」でそのサーバーにチェックが入っているか、サーバーが無効化されていないか確認する（[ツール・スキル・Wikiなどを持たせる](../04-agents/03-attach-tools-and-more.md)） |
