# スキル

この節では、スキルという軽量なコンテキストの作り方と、エージェントとの関係を説明する。

## スキルとは

スキルは、**名前・説明・内容（指示）だけ**でできた、エージェントへ渡す軽量な指示のまとまりである。「特定の作業に関する専門知識」をエージェント本体のシステムプロンプトから切り離して使い回すために使う。構造は自由で、ルール・出力形式・例など、エージェントに必要なものを内容へそのまま書く。

> 画面上はスキルへツールを直接割り当てない。ツールが必要な作業では、エージェント側で該当のスキルとツールを両方選ぶ（[ツール・スキル・Wikiなどを持たせる](../04-agents/03-attach-tools-and-more.md)）。

## 作る

1. 左ナビ「作る → **スキル**」を開く。一覧が出る。
2. 「**新規作成**」を押す。

「**保存設定**」区画に、スキルを識別・バージョン保存するための項目を入力する（`*`は必須）。

| 項目 | 説明 |
|---|---|
| **内部ID** * | 例 `data-analysis`。保存後は変更できない |
| **作業名** * | 下書き段階の作業用の名前 |
| **スキル名** * | 表示名。例 `データ分析` |
| **公開名** * | 例 `data_analysis` |
| **所有者** | 省略可（空欄なら自分の名前） |

続けて、エージェントへ実際に渡す内容を書く。

- **スキルの説明** * … このスキルを**いつ・なぜ**使うべきかを書く（例:「表形式データを分析し、結果を利用者に分かりやすく説明する。」）。細かいルールはここではなく内容へ書く。
- **スキル内容** * … エージェントに必要な指示・形式・制約・例を自由に記述する。文字数がリアルタイムに表示される。

## 保存する

右上の「**バージョンを保存**」を押す。必須項目（内部ID・作業名・スキル名・公開名・スキルの説明・スキル内容）が埋まっていないと押せず、不足項目がボタン近くに表示される。保存に成功すると「**保存しました バージョン `x.y.z`**」が出る。

> 編集途中の内容はブラウザのローカル下書きへ自動保存される。保存せず他画面へ移ろうとすると確認ダイアログが出て、次に開いたときは「未保存の編集内容があります」バナーから「**復元**」か「**破棄**」を選べる。

## 一覧からの操作

一覧の各行から「**開く**」で編集画面へ、「**削除**」（確認ダイアログを経由）で一覧から消せる（保存済みバージョンは履歴に残る）。
