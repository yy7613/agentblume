# メモリとWiki

この節では、エージェントの長期記憶を担う「Wiki」の作り方・編集と、実行から生まれる記憶提案のレビュー方法を説明する。

## 長期記憶の2本柱

AgentBlumeの長期記憶は2種類でできている。

| 柱 | 記憶の種類 | 実体 |
|---|---|---|
| **LLM Wiki** | 宣言的知識（事実・文脈・判断理由） | Wiki空間ごとのMarkdownページ（この節で扱う） |
| **スキルの内容** | 手続き的知識（手順・コツ） | [スキル](./01-skills.md)の内容そのものへの改訂提案 |

どちらも**人の承認を経てから**エージェントへ効く。エージェントが実行のたびに勝手に書き込むことはない。

## 画面の場所

左ナビ「運用 → **記憶**」を開く。「**Wiki**」タブと「**提案**」タブがある。

## Wikiタブ: 空間とページを管理する

Wikiは名前付きの空間（Wiki space）に分かれており、それぞれの中にページを持つ。**顧客・業務・環境ごとにWikiを分けると、エージェントが参照する知識が混線しない**。

### Wiki空間を作る・選ぶ

1. 「**選択中のWiki**」プルダウンで既存のWikiを選ぶか、「**新しいWiki**」を押して新規作成に切り替える。
2. 「**Wiki ID**」「**Wiki名**」（必須）「**説明**」（任意）を入力し、「**Wikiを保存**」を押す。
3. 不要になったWikiは「**Wikiを削除**」で削除できる（配下のページもすべて削除されるため確認ダイアログが出る）。

### ページを編集する

1. 左側の検索欄でページを絞り込む（「**検索**」）か、一覧から直接開く。
2. 「**タイトル**」「**タグ（カンマ区切り）**」「**本文**」を編集する。
3. 「**ページを保存**」を押す。保存すると改訂番号（`v1`, `v2`…）が上がる。
4. 「**新規**」で空の新規ページに切り替えられる。不要なページは一覧の「**削除**」（確認ダイアログあり）で消せる。

作ったWikiは、エージェント編集画面の「**Wiki**」でチェックしたものだけが実行時の検索対象になる（[ツール・スキル・Wikiなどを持たせる](../04-agents/03-attach-tools-and-more.md)）。

## 提案タブ: 記憶の蒸留をレビューする

[動作確認画面](../04-agents/04-chat-and-inspect.md#動作確認画面で詳しく調べる)で「**記憶へ蒸留**」を押すと、その応答をもとに次のいずれかの提案（draft）が作られる。

- **Wiki提案**: 新規ページの作成、または既存ページへの追記案
- **スキル提案**: 対象スキルの内容への改訂案

「提案」タブでは状態別（**未決** / **承認済み** / **却下** / **すべて**）に絞り込んで一覧できる。各カードには対象種別（Wiki / Skill）・要約・提案内容のプレビューが出る。

- 「**未決**」の提案は「**承認**」「**却下**」ボタンを持つ。承認するとWikiページの新しい改訂、またはスキルの新しいバージョンとして書き込まれる（確認ダイアログを経由）。
- 却下すると何も書き込まれず、状態が「却下」に変わるだけである。

## うまくいかないとき

| 症状 | 原因・直し方 |
|---|---|
| ページを保存できない | 「選択中のWiki」が未選択、またはタイトル・本文が空。先にWikiを選ぶか作成する |
| エージェントがWikiの内容を使わない | エージェント側の「Wiki」でそのWikiにチェックが入っていない（[ツール・スキル・Wikiなどを持たせる](../04-agents/03-attach-tools-and-more.md)を参照）。または種別が「疑似ユーザー」でWikiを選べない |
| 記憶へ蒸留しても提案が出ない | 蒸留対象が無い（提案する記憶が無い）と判断された場合は0件のまま。動作確認画面に「提案する記憶はありませんでした。」と出る |
