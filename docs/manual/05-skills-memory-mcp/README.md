# 05 スキル・メモリ・MCP

エージェントに持たせる「知識」と「外部ツール」の3種類を扱う章。スキルは軽量な指示のまとまり、メモリ（Wiki）はエージェントが検索できる宣言的な知識、MCPは外部サーバーが提供するツールをエージェントへ取り込む仕組みである。

- [01 スキル](./01-skills.md) — 名前・説明・内容だけで作る軽量なコンテキスト
- [02 メモリとWiki](./02-memory-and-wiki.md) — Wikiページの管理と、実行から生まれる記憶提案のレビュー
- [03 MCPサーバー](./03-mcp.md) — 外部MCPサーバーの登録と接続テスト
