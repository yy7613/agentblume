# 11 チュートリアル

同梱サンプルを使って、エージェントを 1 体作り上げるまでを通しでやってみる章。各段階で、詳しく説明している章へのリンクを置いている。

| 節 | 内容 | 目安 |
|---|---|---|
| [01 データからエージェントを作る（通し）](./01-build-an-agent-end-to-end.md) | データ確認 → 設計アシスタントと会話してツールを作る → 整列・保存 → エージェントに持たせる → チャットで会話 → ツール検証 | 30〜40 分 |
| [02 Factory で作る](./02-build-with-factory.md) | やりたいこととデータを渡して、ツール・スキル・エージェント一式を自動で作らせる | 入力 5 分 + 待ち時間 |

はじめての人は 01 から読む。01 は本書の中心で、「ツールを自分で（アシスタントと）設計する」流れを 1 本通す。02 は、何から作ればよいかわからないときの近道である。

どちらも、先に [はじめに](../01-getting-started/README.md) の起動とモデルの設定を済ませておく。所要時間の目安は、LM Studio の 12B 級モデル（`google/gemma-4-12b`）を使って実際に通したときのものである。
