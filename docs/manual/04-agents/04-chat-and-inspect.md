# チャットで確かめる・呼び出しを調べる

保存したエージェントは、左ナビ「**チャット**」で普段どおりに会話できるほか、「**動作確認**」画面でツール呼び出し・トークン数・所要時間を1件ずつ観測できる。この節では両方の画面と、呼び出し前に問題を洗い出す「診断」の見方を説明する。

## チャットで会話する

1. 左ナビの「**チャット**」を開く。
2. 入力欄の下にある「**チャット対象エージェント**」のプルダウンでエージェントを選ぶ（`表示名 · バージョン`の形。保存済みの[マルチエージェント](../06-multi-agent/01-multi-agent.md)がある場合は「マルチエージェント」というグループにまとまって並ぶ）。
3. メッセージを入力し `Enter` で送信する（`Shift+Enter`で改行）。

実行中は送信ボタンが**停止ボタン**に変わり、押すと中断できる（入力内容は欄に戻る）。10秒・30秒・2分の節目で「モデルの応答を待っています…」のような状況説明が出る。

### 画像・PDFを添付する

入力欄左のクリップアイコンから添付する。

- **画像**: PNG・JPEG・WebP・GIFを最大2枚、各3 MiBまで。画像入力に対応したモデルが必要で、画像だけでは送信できない（指示文も入れる）。
- **PDF**: 最大2件、各30 MiBまで。ブラウザ側でテキスト層を抜いて添付するため、**PDFの本文はツールの実行文脈だけに渡り、モデルへは載らない**。テキスト層の無い（スキャンした）PDFは添付できず、「契約画面で文字起こししてから使ってください」という案内が出る。

### 会話中に起きること

- 応答の下に、呼んだツール・トークン数（表示言語に合わせて「N トークン」/「N tokens」）・所要時間の要約と、トレース（モデル要求 → ツール呼び出し → ツール結果 → 最終応答）が段階チップで並ぶ。
- 応答の本文に Markdown の表（`| 列 | 列 |` 形式）が含まれていれば、表として描かれる。
- 「**ツール承認**」を有効にしたエージェントが書き込み系ツールを呼ぼうとすると、実行が一時停止して「**承認**」「**拒否**」ボタンが出る。
- 実行に失敗すると、エラーの内容と、直せる箇所への導線（該当ツール・ノードを開くボタンなど）が出る。「**再試行**」で同じ内容のまま送り直せる。
- セッション中に作られた一時Artifact（グラフなど）は右側の「**セッションワークスペース**」に並び、グラフはクリックでプレビューできる。

## 動作確認画面で詳しく調べる

左ナビ「確かめる → **動作確認**」を開くと、チャットと同じように会話しながら、実行1回ごとの中身を詳しく見られる。

1. 「**対象エージェント**」でエージェントを選ぶ。選ぶと能力バー（スキル・ツールの一覧チップ、構造化出力の有無）が出る。
2. 「**ツール診断**」ボタンで、このエージェントに割り当てたツールが呼び出せる状態か（後述の「呼び出し診断」）をその場で確認できる。
3. 指示を入力して送信すると、応答ごとに次の情報が出る。
   - **実行メトリクス**: 所要時間・合計トークン数（内訳: プロンプト → 完了）・ツール呼び出し回数・モデル往復回数。
   - **呼ばれたツール**: ツール名・呼び出し回数・返した行数・引数の一部。
   - **トレース**: `件数 · run ID` を開くと、イベントを1件ずつ番号付きで確認できる。
   - **評価**（Mastra Evals）: 「**応答を評価**」を押すと基準ごとのスコアと平均が出る。
   - **記憶**（蒸留）: 「**記憶へ蒸留**」を押すと、この応答から長期記憶（Wikiページの追記・スキルの改訂）の提案案を作る。作成件数が出るので、内容は[メモリとWiki](../05-skills-memory-mcp/02-memory-and-wiki.md)の「提案」タブでレビューする。
4. さらに「**記憶をアタッチ**」を開くと、Wikiページを手動で選んで今回の実行にだけ注入できる（実行時の自動検索とは別に、狙ったページを確実に渡したいときに使う）。

チャット画面と動作確認画面は同じ実行の仕組みを使うが、動作確認画面は**単体のエージェントだけ**を対象にする（マルチエージェントは選べない）。

## 呼び出し診断（組み込みチェック）

「ツールを割り当てたのに、実際に呼び出せるか」を**実行せずに**確かめる仕組み。次の3か所から使える。

| 場所 | 操作 | 特徴 |
|---|---|---|
| エージェント編集画面 | ヘッダーの「**組み込みチェック**」 | 保存前の下書きに対して検査する。ツール・スキル・サブエージェント・MCP・実行オプション・構造化出力の選択を変えると、少し待って自動でも実行される |
| エージェント編集画面（保存直後） | 自動 | 「**バージョンを保存**」の直後、保存済みバージョンに対して自動で診断が走る |
| 動作確認画面 | 「**ツール診断**」ボタン | 保存済みエージェントに対して手動で実行する |

結果は検査ごとに ✓（問題なし）・`!`（警告）・`✕`（エラー）で表示され、問題のある行には原因の説明と「**直す場所を開く**」系のボタンが付く。ボタンを押すと、該当する画面の区画（ツール選択・サブエージェント選択・MCP設定・モデル設定・実行オプションなど）へ直接移動できる。

検査項目の例:

| 検査 | 内容 |
|---|---|
| スキル参照 | 選んだスキルが解決できるか |
| ツールバージョン整合 | 選んだツールのバージョンが存在するか |
| サブエージェント参照 | 委譲先のエージェントとバージョンが存在するか |
| Function名の一意性 | ツール・サブエージェントの公開名が関数名として重複・不正でないか |
| MCPサーバー参照 | 選んだMCPサーバーが登録されているか |
| モデルの対応機能 | 設定中のモデルが構造化出力など必要な機能に対応しているか |
| ハーネス機能の前提 | 実行オプションで有効にした機能の前提（Web検索のプロバイダ設定など）が揃っているか |

## うまくいかないとき

| 症状 | 原因・直し方 |
|---|---|
| チャットで「エージェントを選んでください」のまま進まない | 保存済みのエージェントが無い。先に[エージェントを作る](./02-create-agent.md)で1つ保存する |
| 実行が長い間終わらない | エージェント実行はタイムアウトまで最大10分かかることがある。待てない場合は停止ボタンで中断し、短い指示で試し直す |
| 診断で「エラー」バッジが出る | バッジや詳細行の「**直す場所を開く**」ボタンから該当箇所（ツール選択・サブエージェント委譲基準・MCP設定など）を開いて直す |
