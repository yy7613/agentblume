# ツール・スキル・Wikiなどを持たせる

エージェントの編集画面には、定義とシステムプロンプトの間に、割り当てを選ぶ区画が並ぶ。この節ではそれぞれの選び方と、選ぶと何が起きるかを説明する。

## スキル

「**スキル**」の一覧からチェックで選ぶ。選んだ件数が見出し横に「◯件選択」と出る。保存済みスキルが無い場合は「保存済みスキルがありません。」から「**スキル画面を開く**」で作成に移れる。スキルの作り方は[スキル](../05-skills-memory-mcp/01-skills.md)を参照。

## ツール

「**ツール**」の一覧からチェックで選ぶ。ツールを1つも選ばないと「ツールが選択されていません。データに関する質問には答えられません。」という注意が保存ボタン近くに出る（保存は止めない）。

診断を実行した後は、選択済みのツール行に診断バッジ（✓ 問題なし / `!` 警告 / `✕` エラー）が付く。バッジにマウスを載せると最初の問題の内容が出る。診断の詳しい見方は[チャットで確かめる・呼び出しを調べる](./04-chat-and-inspect.md#呼び出し診断組み込みチェック)を参照。

## サブエージェント

他の保存済みエージェントへ「委譲」できる。選ぶとそのエージェントは `ask_<公開名>` という名前のツールとしてモデルへ提示され、モデルが呼ぶと委譲先のエージェントが独立した実行として走り、その最終応答が結果として返る。

1. 「**サブエージェント**」の一覧から委譲したいエージェントにチェックを入れる（自分自身は一覧に出ない）。
2. チェックした行の下に現れる入力欄へ、**どんな時にここへ委譲するか**を文章で書く（例:「売上の数値分析が必要なとき」）。この「委譲基準」は選んだサブエージェントすべてで必須で、空欄のままだと保存できない。
3. 1件以上選ぶと「**実効副作用**」が表示される。これは自分のツールと、委譲先（さらにその先も再帰的に）が持つ副作用のうち最も強いもので、`read-only`（読み取り専用）より強いと、動作確認画面などの**previewでは実行できない**ことがある。概算値であり、確定した判定は保存時にサーバー側で行われる。

保存済みエージェントが他に無い場合は「委譲できる他の保存済みエージェントがありません。」と出る。

## Wiki

「**Wiki**」の一覧からチェックで選ぶ。**実行時に検索できるのは、ここで選んだWiki内のページだけ**である。Wikiを分けることで、顧客や業務ごとに知識が混線しないようにできる。Wikiが無い場合は「先に記憶画面でWikiを作成してください。」から「**記憶画面を開く**」で作成に移れる。作り方は[メモリとWiki](../05-skills-memory-mcp/02-memory-and-wiki.md)を参照。

> 種別が「疑似ユーザー」のエージェントはWikiを選べない（チェックボックスが無効化される）。

## MCPサーバー

「**MCPサーバー**」の一覧からチェックで選ぶ。選んだサーバーが持つツールは `mcp__<サーバー名>__<ツール名>` という名前でエージェントへ注入される。最大8件まで選べる（超えると未選択行のチェックが押せなくなる）。

- サーバー一覧が空のときは「MCPサーバーが未設定です。MCP画面で追加してください。」と出る。登録方法は[MCPサーバー](../05-skills-memory-mcp/03-mcp.md)を参照。
- 一覧の行に「実行時はスキップ」と出ているサーバーは無効化されている（実行時にツールが注入されない）。
- 以前選んでいたが、その後MCP画面から削除されたサーバーは「**未登録**」のバッジ付きで残る。実行時は静かにスキップされるだけなので、不要ならチェックを外して保存し、参照を落とすとよい。

## 実行オプション（このエージェントだけの実行時機能）

ヘッダーの「**実行オプション**」ボタンを押すと、このエージェント単位でオン・オフできる機能のダイアログが開く。設定済みの場合はボタンの文字列に有効な項目数が `(件数)` として続けて表示される。

| 機能（画面表記） | 内容 | 既定 |
|---|---|---|
| ファイルメモリ | セッションをまたいで残るメモ（`memory_*`ツール、Wiki保存） | オフ |
| TODOリスト | 複数ステップ計画の管理（`todos_add` / `todos_complete`） | オフ |
| コンパクション | 長いツールループの文脈を自動圧縮 | オフ |
| Web検索 | `web_search`ツールを注入（検索プロバイダの設定が必要） | オフ |
| ツール承認 | 書き込み系ツールの実行前に承認を要求 | オフ |
| ツール自動実行 | ツール呼び出しの自動ループ（オフだと1回応答のみでツールを呼べない） | **オン** |

未設定のまま（ダイアログを開かずに保存する）だと、従来どおりの動作になる。「**未設定に戻す**」でこの状態へ戻せる。

> **別概念の注意**: この実行オプションは1つのエージェントに対する設定であり、[マルチエージェント](../06-multi-agent/01-multi-agent.md)画面（複数のエージェントを組み合わせる機能）とは別物である。混同しないこと。
