# エージェントとは

この節を読むと、AgentBlumeでの「エージェント」が何でできているかが分かり、次の節から迷わず組み立てられるようになる。

## 指示文＋参照するもの＋モデル

エージェントは次の3つでできている。

| 要素 | 内容 |
|---|---|
| **システムプロンプト（指示文）** | 役割・制約・応答スタイルを日本語（または英語）の自由文で書く。エージェントの人格に当たる部分で、必須項目である |
| **参照するもの** | **スキル**（指示のまとまり）・**ツール**（データを決まった手順で加工する部品）・**Wiki**（宣言的な知識）・**MCPサーバー**（外部ツール）・**サブエージェント**（他の保存済みエージェントへの委譲）。どれも0個でよいが、ツールが1つも無いとデータに関する質問には答えられない |
| **モデル** | 実際に応答を生成するLLM。エージェント自体はモデルを保持せず、実行時にワークスペースの「**メインモデル**」スロット（左ナビ「運用 → 設定」の「モデルプロバイダ」）の設定を使う |

会話が来ると、エージェントはシステムプロンプトと参照するものの一覧（ツールの説明・スキルの内容など）をモデルへ渡す。モデルが「このツールを呼びたい」と判断すると、**ツールはLLMを介さずに決定的に実行**され、結果だけがモデルへ戻る。スキルやWikiはモデルが読む文脈を増やすだけで、それ自体は実行されない。ツールの作り方は[03 ツールを作る](../03-tools/README.md)を参照する。特にツールを日本語で会話しながら組みたい場合は[設計アシスタント](../03-tools/05-design-assistant.md)が使える。

## 画面の場所

左ナビ「作る」グループの「**エージェント**」を開く。画面は一覧（保存済みエージェントの表）と編集の2段構えである。

- 一覧では表示名・`公開名@最新バージョン`・種別・状態が並び、「**開く**」で編集画面へ、「**削除**」（確認ダイアログを経由）で一覧から消せる（保存済みのバージョンは履歴に残る）。
- 一覧が空のときは「**エージェントはまだありません。**」と、Factory（目的とデータから自動生成する画面）への案内が出る。

## ツールとの違い

初めての人が迷いやすいのが「ツールとエージェントの違い」である。

| | ツール | エージェント |
|---|---|---|
| 何をするか | 入力 → 変換 → 出力の流れ図で、決まった手順どおりにデータを加工する | システムプロンプトに従ってモデルが判断し、必要ならツールを呼ぶ |
| LLMを使うか | 使わない（呼ぶたびに同じ入力なら同じ結果になる） | 使う（同じ指示でも応答が変わり得る） |
| 向いている作業 | 集計・並べ替え・絞り込みなど「確実な数字や一覧」が欲しい作業 | 質問への回答・要約・判断など「言葉での応答」が欲しい作業 |

エージェントは会話の窓口であり、**計算やデータ加工はツールへ、判断や言語処理はエージェント自身（または委譲先のサブエージェント）へ**という役割分担で組み立てる。ツールの作り方は[03 ツールを作る](../03-tools/README.md)を参照する。

## 種別（Kind）

エージェント作成時に「**種別**」を選ぶ。ほとんどの場合は既定の「**通常**」でよい。

| 種別（画面表記） | 用途 |
|---|---|
| 通常 | チャットで会話する普通のエージェント。以降の節はこれを前提にする |
| 疑似ユーザー | 検証機能で「利用者になりきって会話する」ために使う特殊な種別。詳しくは[08 シナリオとペルソナ](../08-validation/02-scenarios-and-personas.md) |
| 評価者 | 検証機能で回答を採点するために使う特殊な種別。詳しくは[08 検証する](../08-validation/README.md) |
