# 01 設定画面

左ナビ「運用 → **設定**」に何が並んでいるかを一覧する。この節を読むと、モデル設定以外にどんな項目があり、それぞれで何ができるかが分かる。

## 開き方

1. 左ナビの「**運用**」グループから「**設定**」を選ぶ。
2. 画面上部に見出し「**実行環境設定**」と説明「ローカル実行環境と安全境界を確認します。」が出る。右上の「**状態を更新**」を押すと、下の「接続」カードのAPI状態を再確認する。

画面はカードの集まりで、上から順に「言語」「実験的な機能」「接続」「アクセス」「環境変数の既定」「安全ゲート」、そして最後に「**モデルプロバイダ**」（メインモデル・評価モデルの2スロット）が続く。モデルプロバイダの詳しい入力手順は[はじめに §モデルの設定](../01-getting-started/02-model-settings.md)にあるので、ここでは残りのカードを説明する。

## 言語

「**表示言語**」のプルダウンで English / 日本語 を切り替える。選択はこのブラウザに保存される（サーバー側の設定ではない）。

## 実験的な機能

チェックボックス「**実験的な機能を表示する**」がある。オンにすると、左ナビに**業務テンプレート**（仕訳・経費精算・入金消込・契約書レビュー）が表示されるようになる。画面・保存データの形式・判定のルールは今後変わることがあるため、初期状態では非表示になっている。選択はこのブラウザに保存される。

業務テンプレートを使い始める前に、必ずこのトグルをオンにする。詳しくは[09 業務テンプレート](../09-business-templates/README.md)を参照。

## 接続

サーバー（API）との疎通状態を表示するカード。

- **API** … 「確認中」「正常」「オフライン」のいずれかが、色付きの丸と一緒に出る。「オフライン」のときは隣の「**再確認**」で再チェックできる。
- **スコープ** … 今つながっているテナントID / ワークスペースIDを`tenantId / workspaceId`の形で表示する（参照のみ。ここから変更する手段はない。スコープの決まり方は[03 利用者と権限](./03-users-and-permissions.md)を参照）。

## アクセス

利用者が誰として扱われているかを示すカード。表示内容は認証方式によって変わる。

- **単一ユーザーモード**（既定・資格情報なし）のときは、次の2文が出るだけである。
  - 「単一ユーザーモードです。リクエストは認証されていません。この状態では 127.0.0.1 以外へバインドするとサーバーは起動しません。」
  - 「チームで共有する場合は、サーバーに AGENTCONTEXT_AUTH_TOKENS を設定して再起動してください。」
- **共有トークン認証**が設定されている環境では、「**認証中**」欄に自分の表示名（無ければ利用者ID）が出て、「**アクセストークン**」欄にトークンを貼って「**トークンを保存**」で認証する。認証済みなら「**サインアウト**」でブラウザからトークンを消せる。トークンはこのブラウザにのみ保存される。

2つの方式の違いと、ロールで何ができるかは[03 利用者と権限](./03-users-and-permissions.md)にまとめてある。

## 環境変数の既定

モデルのスロット（メイン・評価）を未設定のままにしたときに使われる、サーバー側の環境変数を一覧するカードである。

| 項目 | 環境変数 |
|---|---|
| プロバイダー | （固定）LM Studio · OpenAI compatible |
| エンドポイント | `LM_STUDIO_BASE_URL` |
| モデル | `LM_STUDIO_MODEL` |
| タイムアウト | `LM_STUDIO_TIMEOUT_MS` |

サーバー側の環境変数なので、このカードからは変更できない（参照のみ）。変数の一覧は[付録 環境変数](../appendix/02-environment-variables.md)を参照。

## 安全ゲート

現在有効・無効な安全機構を一覧するカードである（v53で実装状況に合わせて更新された）。次のように出る。

- 有効: 「プレビューでは書き込みToolを遮断」「実行トレースの永続化が有効」「テナントスコープは認証済みPrincipalから決まる」「ロールベースの認可（RBAC）を全ルートに適用」「削除・承認・公開・実行は監査ログに記録」「MCPサーバー設定の変更にはOperator権限が必要」
- 無効（ロック表示）: 「本番実行は利用不可」

現在の正確な状態、ロールごとにできることは[03 利用者と権限](./03-users-and-permissions.md)で確認すること。

## うまくいかないとき

| 症状 | 原因 | 直し方 |
|---|---|---|
| 「接続」のAPIが「オフライン」のまま | APIサーバーが落ちている、またはポートがずれている | 「**再確認**」を押す。直らないなら[04 困ったとき §画面がAPIに繋がらない](./04-troubleshooting.md) |
| 「実験的な機能」をオンにしても業務テンプレートが左ナビに出ない | 別のブラウザ・別のプロファイルで開いている（設定はブラウザ保存） | 同じブラウザで開き直す。それでも出なければ画面を再読み込みする |
| 「アクセス」に「未認証」しか出ない・トークンを保存してもエラーになる | トークンが違う、または`AGENTCONTEXT_AUTH_TOKENS`側の設定と噛み合っていない | [03 利用者と権限](./03-users-and-permissions.md)を参照 |
