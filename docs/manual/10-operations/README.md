- [01 設定画面](./01-settings.md) — 「設定」画面のカード一覧（モデル以外の項目を中心に）
- [02 データの置き場所とバックアップ](./02-data-and-backup.md) — DBファイル・アーティファクト・暗号鍵の関係、バックアップと保持期限
- [03 利用者と権限](./03-users-and-permissions.md) — 単一ユーザーモードと共有トークン認証、ロールでできること
- [04 困ったとき](./04-troubleshooting.md) — 症状から探すトラブルシューティング

モデルの設定手順そのものは[01 はじめに §モデル設定](../01-getting-started/02-model-settings.md)にある。本章では設定画面の全体像と、モデル以外の項目を扱う。
