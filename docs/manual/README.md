# AgentBlume 利用マニュアル

AgentBlume で**自分の業務に使えるエージェントを作れるようになる**ための手順書。データを登録し、エージェントが呼ぶツールを（設計アシスタントと会話しながら）組み、エージェントに持たせて会話し、検証してから使い始めるまでを、章ごとに説明する。

- 対象: AgentBlume を使ってエージェントを作る人。プログラミングの知識は要らない（起動時に PowerShell でコマンドを 1〜2 行打つ場面はある）。
- 画面表記: **日本語表示**を前提にする（「設定」→「表示言語」で切り替えられる）。
- 設計の背景や API の詳細は、開発者向けの [docs/](../README.md)（01〜23 と ADR）にある。本書は「画面で何をするか」に絞る。

## はじめての人の読み順

1. [はじめに](./01-getting-started/README.md) — 起動・モデル設定・画面の歩き方・10 分でサンプルのエージェントと会話する
2. [チュートリアル: データからエージェントを作る](./11-tutorials/01-build-an-agent-end-to-end.md) — 本書の中心。データ登録 → 設計アシスタントとツールを作る → エージェントに持たせる → 検証する、を 1 本通す
3. あとは必要な章を辞書的に引く
