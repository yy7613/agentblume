# インストールと起動

この節では、自分のPCに AgentBlume を入れて起動できるようになる。起動方法は2つあり、日々使い方を試す人向けの「開発用起動」と、普段使いする人向けの「ビルドして起動」を両方説明する。

## 前提

| 項目 | 必要なバージョン | 確認方法 |
|---|---|---|
| Node.js | 22.9.0 以上 | PowerShellで `node -v` |
| PowerShell 7（`pwsh`） | 開発用起動（方法A）を使う場合のみ必要 | `pwsh -v` |

Node.js が無い、または古い場合は [nodejs.org](https://nodejs.org/) から LTS 版を入れる。PowerShell 7 が無い場合は、開発用起動を使わず、後述の「方法B: ビルドして起動する」だけを使えばよい。

## 1. インストールする

リポジトリを取得したフォルダで、PowerShellを開いて次を実行する。

```powershell
npm install
```

依存パッケージのダウンロードが終わればインストール完了。エラーが出る場合はまず Node.js のバージョンを確認する（うまくいかないとき参照）。

## 2. 起動する

起動方法は2つある。試しながら使うなら方法A、普段使いするなら方法Bを選ぶ。

### 方法A: 開発用に起動する

1. PowerShellで次を実行する。

   ```powershell
   .\scripts\start-dev.ps1
   ```

2. 起動すると、APIが既定ポート `3030`、UIが既定ポート `5173` で立ち上がる。ブラウザで `http://127.0.0.1:5173` を開くと画面が出る。
3. 止めるときは、起動したPowerShellウィンドウで `Ctrl+C` を押す。

**ポートが既に使われている場合**、既存プロセスは自動では止まらず、エラーになる。次のどちらかで対処する。

- 前回の異常終了などで残ったプロセスを掃除する。

  ```powershell
  .\scripts\start-dev.ps1 -Stop
  ```

- 別のポートを指定して起動する（API・UIの両方を同時に指定するのが確実）。

  ```powershell
  .\scripts\start-dev.ps1 -ApiPort 3031 -UiPort 5174
  ```

### 方法B: ビルドして起動する

1. ビルドする。

   ```powershell
   npm run build
   ```

2. 起動する。

   ```powershell
   npm start
   ```

3. ブラウザで `http://127.0.0.1:3030` を開く。UIとAPIが同じポートから配信されるので、開くURLはこれだけでよい。

## 認証機能が無いことに関する注意

AgentBlume には**利用者ごとの認証機能がまだ無い**。既定の接続先（`127.0.0.1`）はこのPCの中だけに閉じているため問題ないが、環境変数 `AGENTCONTEXT_HOST` を `0.0.0.0` などループバック以外に変更して社内LANやインターネットへ公開すると、資格情報なしで誰でもこのワークスペースの全データ（登録済みのAPIキーを含む）を触れるようになる。**チームで共有したい場合でも、`AGENTCONTEXT_HOST` を安易に変えて公開しないこと。**

## うまくいかないとき

| 症状 | 原因 | 直し方 |
|---|---|---|
| `npm install` が失敗する、起動時に engine の警告が出る | Node.js が 22.9.0 未満 | PowerShellで `node -v` を確認し、[nodejs.org](https://nodejs.org/) からLTS版を入れ直す |
| `.\scripts\start-dev.ps1` が「用語 … は認識されません」になる | PowerShell 7（`pwsh`）が入っていない | `pwsh -v` で確認する。入れるか、方法B（`npm run build` → `npm start`）を使う |
| 「APIポート … は使用中です」 | 前回の起動が残っている、または他のアプリが同じポートを使っている | `.\scripts\start-dev.ps1 -Stop` で掃除するか、`-ApiPort` / `-UiPort` で別ポートを指定する |
| 起動時に環境変数のエラーが並んで止まる | `.env` の値が不正 | 表示された変数名を確認し、値を直す |
