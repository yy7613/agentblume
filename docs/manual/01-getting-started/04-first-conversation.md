# サンプルを読み込んで最初の会話（10分）

この節では、あらかじめ用意されたサンプルデータを読み込んで、実際にエージェントと会話してみる。自分のデータを用意する前に、動いている状態を一度見ておくと理解が早い。モデルの設定（[02-model-settings.md](./02-model-settings.md)）を先に済ませておくこと。

## サンプルを読み込む

1. 左ナビの「**チャット**」を開く。データが何も無い状態だと「**AgentBlumeへようこそ**」というカードが画面上に出る。
2. カードの「**サンプルを読み込んで試す**」を押す。
3. 読み込みが終わると、「サンプルを読み込みました（新規N件）。」という結果と、追加されたデータソース・エージェントの名前が一覧で出る。「**サンプルのエージェントと話す**」ボタンが現れるので押すとチャットへ戻る。

> ウェルカムカードが出ない場合（既に何かデータがある場合など）は、左ナビ「**データソース**」画面の「**サンプルを読み込む**」ボタンからでも同じことができる。既に読み込み済みなら「サンプルは既に読み込み済みでした（変更はありません）。」と出るだけで、何度押しても安全（同じIDのものは作り直さない）。

## 投入される一式

「サンプルを読み込んで試す」を押すと、次の一式が追加される。

| 種別 | 名前 | 内容 |
|---|---|---|
| データソース | `sample-products.csv` | 商品3件 |
| データソース | `sample-customers.json` | 顧客2件 |
| データソース | `sample-monthly-sales.csv` | 月次売上6行 |
| ツール | `Sample Product Catalog` | 商品カタログをエージェントへ返す |
| スキル | `Sample Product Analysis` | カタログに基づく回答規則 |
| Wiki | `Sample Product Operations` | 在庫・価格・カテゴリの判断規則 |
| エージェント | `Sample Product Assistant` | 上の3つ（ツール・スキル・Wiki）を割り当てたデモ用エージェント |

## エージェントと会話する

1. 左ナビの「**チャット**」を開く。
2. 入力欄の下にある「**チャット対象エージェント**」のプルダウンで `Sample Product Assistant · 1.0.0` を選ぶ。
3. 質問を入力欄に打ち、`Enter` で送信する（改行したいときは `Shift+Enter`）。

試しやすい質問の例:

```text
在庫のあるelectronics商品を価格付きで比較して。
```

## 実行中と応答のあと

- 実行中は入力欄右のボタンが「**実行を中断**」（停止ボタン）に変わる。時間がかかりすぎると感じたら押せば中断でき、入力した内容はそのまま入力欄へ戻る。
- 応答の下には、エージェントが呼んだツール名と引数が実行ステップとして並び、末尾に実行IDとトークン数が出る。**何が起きたかをもっと詳しく見たい**ときは、左ナビの「**動作確認**」画面で同じ質問を送ると、モデル要求 → ツール呼び出し → ツール結果 → 最終応答のトレースを1件ずつ、所要時間つきで確認できる。

## 画像を添付する

入力欄左のクリップアイコン「**画像を添付**」から画像を選ぶと、質問と一緒に画像を送れる。

- 対応形式は PNG・JPEG・WebP・GIF。
- 最大2枚まで、1枚あたり3 MiBまで。
- 画像だけでは送信できない。指示文も必ず入力する。
- 画像を理解できるモデル（vision対応）が設定されている必要がある。

## うまくいかないとき

| 症状 | 原因 | 直す場所 |
|---|---|---|
| ウェルカムカードが出ない | 既に何かデータが登録されている | 「データソース」画面の「サンプルを読み込む」ボタンを使う |
| 質問を送ってもエージェントが応答しない | モデルが未設定 | 「設定」画面でメインモデルを保存する（[02-model-settings.md](./02-model-settings.md)） |
| 「選択中のモデルはツール呼び出しに対応していません」と出る | 選んでいるモデルがTool Calling非対応 | 「設定」画面でTool Calling対応モデルへ替える |
| 画像を添付できない | 枚数（2枚）・サイズ（3 MiB）の上限を超えている、または対応形式でない | PNG/JPEG/WebP/GIFで、2枚・各3 MiB以内に収める |
