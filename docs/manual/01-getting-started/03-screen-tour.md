# 画面の歩き方

この節を読むと、左ナビに並ぶ画面が何をする場所かが分かり、迷わず目的の画面へ行けるようになる。

## 左ナビの構成

画面はブラウザの左側に縦に並ぶ。一番上が「**チャット**」、その下に3つのグループ（「**作る**」「**確かめる**」「**運用**」）が続く。

```
チャット

作る
  データソース
  ツール
  スキル
  エージェント
  マルチエージェント
  自動生成 (Factory)
  業務テンプレート   ← 実験的な機能。既定では出ない

確かめる
  動作確認
  ツール検証
  検証

運用
  記憶
  MCP
  ステータス
  設定
```

## チャット

保存済みのエージェント（またはマルチエージェント）をバージョン固定で実行し、どのツールを呼んだかを確認する画面。何もデータが無い状態では「AgentBlumeへようこそ」のカードが出る（[04-first-conversation.md](./04-first-conversation.md)）。

## 「作る」グループ

エージェントを組み立てるための画面が並ぶ。上から使う順に並んでいる。

| 画面 | すること |
|---|---|
| **データソース** | ツールが読み取るCSV/JSONファイルとデータベース接続を登録する。 |
| **ツール** | データ処理（ソース → 変換 → 出力）をキャンバスで組み立て、エージェントが関数として呼べる部品にする。 |
| **スキル** | エージェントが文脈として読み込む、再利用可能な指示（いつ・何を出力するか）を書く。 |
| **エージェント** | スキル・ツール・Wiki・MCPサーバーを束ねてエージェントを組み立て、バージョンとして保存する。 |
| **マルチエージェント** | 保存済みのエージェント複数を、1つのオーケストレーションパターン（逐次・handoff・並行など）へ組み立てる。 |
| **自動生成 (Factory)** | やりたいことを文章で書き、データソースを選ぶと、ツール・スキル・エージェントと検証資産をdraftとして自動生成し、改善ループを回す。 |
| **業務テンプレート** | 仕訳・経費精算のような、特定の業務向けにあらかじめ組んである機能の入口。**実験的な機能**なので既定では表示されない（下記「業務テンプレートを表示するには」を参照）。 |

## 「確かめる」グループ

作ったものが期待どおり動くかを確かめる画面が並ぶ。

| 画面 | すること |
|---|---|
| **動作確認** | 保存済みエージェントへ1回だけ指示を送り、どのツールが動いて何が返ったか、トークン数・所要時間を詳細に確認する。チャットの回答がおかしいときの原因調査に使う。 |
| **ツール検証** | 保存済みツールを単体で実行し、期待する結果（行数・列・値・所要時間）と比べて合否を確認する。ケースとして保存すれば、変更後の退行確認に使える。 |
| **検証** | ペルソナとシナリオを定義してエージェントに実行させ、結果を採点してからバージョンを昇格する。 |

## 「運用」グループ

日々の運用に使う画面が並ぶ。

| 画面 | すること |
|---|---|
| **記憶** | エージェントが実行時に参照できるWikiページを持ち、過去の実行から抽出された記憶の提案を確認する。 |
| **MCP** | エージェントが呼べる外部MCPサーバーを登録する。 |
| **ステータス** | 保存済みの実行とトレースを閲覧し、データベースのバックアップ作成・復元を行う。 |
| **設定** | 表示言語とモデルプロバイダを設定する（[02-model-settings.md](./02-model-settings.md)）。 |

## 業務テンプレートを表示するには

「業務テンプレート」は実験的な機能なので、初期状態では左ナビに出ない。表示するには次の手順を踏む。

1. 左ナビの「**運用**」グループから「**設定**」を開く。
2. 「**実験的な機能**」の「**実験的な機能を表示する**」をオンにする。

この選択は使っているブラウザに保存される。詳しくは[09 業務テンプレート](../09-business-templates/README.md)を参照。

## 今の画面の説明を見る

左ナビの一番下にある「**? ヘルプ**」を押すと、いま開いている画面が何をする場所かの短い説明と、次にすることの手順がダイアログで出る。迷ったらまずここを押すとよい。
