# 08 検証する

作ったツール・エージェントが期待どおり動くかを確かめる章。ツール単体の確認、疑似ユーザーとの会話によるエージェント検証、LLMによる回答採点、公開前の品質ゲートまでを扱う。

- [01 ツールを検証する](./01-tool-check.md) — ツール単体に期待値付きのテストケースを作って実行する（「確かめる → ツール検証」画面）
- [02 シナリオとペルソナ](./02-scenarios-and-personas.md) — 疑似ユーザー（ペルソナ）を作り、複数ターンの会話でエージェントを検証する
- [03 評価データセットと実験](./03-datasets-and-experiments.md) — 事例を集めてデータセットにし、ルーブリックでLLM採点する実験を回す
- [04 品質ゲート](./04-quality-gate.md) — 実験結果をしきい値で合否判定し、公開の可否を決める
