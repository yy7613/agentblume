# v53: マニュアル作成の実機確認で見つかった不具合を直す

マニュアル（docs/manual/）を実機で書いたときに見つかった不具合。どれも「画面が黙って間違う」か「日本語の画面に英語が出る」類。

## F1（最重要）説明文が黙って捨てられる

- 現状: `src/ui/tool-builder/store.ts` の `agentToolOf` は「ツール名（agentName）」と「説明（agentDescription）」の**両方**が入っているときだけ保存ペイロードに `agentTool` を載せる。設計アシスタントは説明文だけを書く（名前は空のまま）ので、保存すると説明文が警告なしに消える。
- 直す: 片方だけ入っているときも載せる。名前が空なら `publishName`（モデルに見える実際の関数名。`effectiveFunctionName` と同じ）、説明が空なら読み込み時と同じ既定（`${displayName} (${sideEffect})`）で補う。両方空なら従来どおり載せない。`effectiveFunctionName` の結果は変えない（名前が空なら publishName のまま）。
- 補った名前が関数名の規則に合わない（publishName が規則外）ときは保存を止め、「ツール名」欄へ導く既存の保存ブロッカーの形で理由を出す（黙って落とさない）。
- テスト: 説明だけ・名前だけ・両方・両方空、の 4 通りで保存ペイロードを固定。設計アシスタントが説明文を書いた後に保存すると説明文が載る。

## F2 日本語の画面に英語が出る

| 場所 | 現状 | 直す |
|---|---|---|
| 設計アシスタントの変更一覧 | `added filter 'filter-region' after …` などサーバーの英文のまま | UI の `src/ui/api/error-messages.ts`（既存の `localizeDesignChatDetail` と同じ作法）で変更一覧の定型文を日本語にする。サーバーの英文は変えない（モデルと API の契約） |
| キャンバスのノードのカード | 型名が英語（`CSV source`・`Filter`） | パレット・設定欄と同じ日本語名（`node-catalog.ts` の日本語ラベル）を出す |
| テンプレートの必須スロット未選択 | 「「Default granularity」を選んでください」 | スロットの日本語ラベルで出す（テンプレートにラベルが無ければ UI 側の訳） |
| Factory 画面 | 計画承認の `Review the proposed plan for …`、レポート総括 `Factory run stopped after …`、候補がエージェントの UUID | 日本語の文にする。候補は表示名（無ければ内部ID）で出す |
| 検証画面 | `Judge Rubric`、版種別（patch/minor/major）、ケース種別、メトリクス種別、設問型、実行/実験の状態語、品質ゲートの `PASS`/`FAIL` など | 日本語表示では日本語にする（値そのもの＝保存データは変えない。表示だけ訳す） |
| ツール検証 | `latest`、` · nullable` の英語の残り | 日本語にする |
| チャットの応答フッター | `N tokens` が英語固定 | 言語に従う |

## F3 設計アシスタントのその他

- **ノードが画面外に出る**: 既存のキャンバスへノードを足したとき、足したノードが表示範囲の外なら表示を合わせる（全体に fitView するか、足したノードが見える位置へ移る）。パレットに隠れてクリックできない状態を作らない。
- **モデル未設定の案内が関数電卓用の文**: 設計アシスタントでは設計アシスタント用の文にし、設定画面の実際の見出し「モデルプロバイダ」へ導く。
- **返答の文と実際の変更が食い違う・頼んでいない変更が入る**: `prompts/tool/design-chat.md` の規則に「返答文は返した操作だけを述べる（操作を返さないなら『変更していない』と言う）」「頼まれていないキー・列・ノードを足さない。足す必要があるなら理由を返答文で述べる」を足し、版を上げる。画面では変更一覧（F2 で日本語化）が正であることを返答の下に示す。

## F4 チャットと設定

- **チャットで Markdown の表が描かれない**: アシスタントの応答の Markdown 表（`| a | b |`）を表として描く（既存の Markdown 描画に表を足す。HTML の生挿入はしない＝ XSS を作らない）。
- **設定画面の「安全ゲート」カードが古い**: 「ロールベースの認可は未実装」「監査アダプター実装まで MCP 公開をロック」等、docs/08 の実装状況（RBAC・監査ログ実装済み）と食い違う文を、現状に合わせる。現状はコード（認証モード・認可・監査の実装）から確かめて書く。
